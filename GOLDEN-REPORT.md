# THE GOLDEN REPORT

## ROOF/OS Report Template — v1.0

Drafted 2026-10-01 · Voice: **We educate. You decide.**

## Rules that govern every word

1. Every sentence must be readable by a 6th grader.
2. Every claim must point to a fact: a photo, a date, a measurement, a code, or a storm record.
3. No sales language. No hedging. Do not write “we believe,” “it appears,” or “our analysis suggests.”
4. One report. No simplified version. This is the standard.
5. AI does not write about money. A human enters and approves every dollar figure.
6. If a fact is unknown, the report says **Unknown**. It does not guess.
7. Every image has plain alt text.
8. Every section can be read aloud on its own.

## Section 1 — Cover

**ROOF INSPECTION REPORT**

- Prepared for: [Homeowner name or Unknown]

This report describes the roof at the address above. It is based on on-site photos and the sources listed in this report. Each observation can be checked. Unknown facts are marked Unknown.

**We educate. You decide.**

## Section 2 — What we looked at

List each photo. Say whether it was usable. If it was not usable, say why and whether a new photo was requested. Do not guess what a photo shows. Give every image plain alt text.

## Section 3 — What we saw

List each observation in a short, plain sentence and name its source photo. If AI first found an observation, a technician must confirm it before the observation appears here.

## Section 4 — What we did not see

List what the photos did not show. If the photo review did not record this, write **Unknown**. Never guess.

## Section 5 — Storm history

List date-based events for this address from the NOAA Storm Events Database. Link each event to its NOAA record. List only recorded events. Do not infer a storm or a date of loss.

## Section 6 — Measurements

Every number must name its source:

- Aerial imagery measurement: name the source and capture date.
- Technician measurement: name the technician and date.
- Calculated from verified inputs: name the inputs and calculation source.

Include roof area (squares), pitch, ridge, eave, rake, valley, gutter, fascia, and soffit. Write **Unknown** when a value or its source is missing. Do not show a number without its source.

## Section 7 — Verification

The technician signs off on what is authoritative and what is not.

- Verified by: [Technician name or Unknown]
- Verified on: [Date and time or Unknown]
- Verified values: [List]
- Corrected values: [List, or Unknown]
- Unverified: [List]

Until this section is signed, the report is a draft. A recorded account approval is not a signature.

## Section 8 — Applicable building codes

Use codes for the actual address jurisdiction. Cite the code body and section number for each rule. Do not assume a national code or paraphrase without a citation. Write **Unknown** if the jurisdiction or code source is missing.

## Section 9 — Projected supplements

List possible future scope items as **Projected**, not approved. Link each item to a verified observation or a cited code. Do not promise that an item will be added. Write **Unknown** when there is no supported item.

## Section 10 — What this report is not

This report is not:

- A certified measurement.
- An engineering determination.
- An insurance claim decision.
- A code compliance certification.
- A final estimate or price.

This report is a set of observations, sources, and calculations for the property owner. It is based on on-site photos and the sources named in the report. Its purpose is education.

This section is never optional. It is never shortened.

## Section 11 — Questions

List homeowner questions with plain, sourced answers. Write **Unknown** if no question or answer is recorded. Route questions about money or insurance decisions to a human.

## How the app uses this template

The app assembles the report from saved photo, inspection, and technician-verification records. AI does not write the report story or decide measurements, prices, insurance outcomes, engineering, or code compliance. An AI observation stays out of the report until a technician confirms it. A rules check requires a source for each claim and writes **Unknown** when a source is missing. A technician must sign Section 7; an owner or manager must approve the report before delivery. Until then, the report is a draft and is not sent to a homeowner.

## The one test

Every report the app produces is checked against this template.

If it fits, every blank is sourced or marked **Unknown**, and no rule is broken, it is ready for human review.

If it does not, it does not ship.
