# ROOF/OS storm theme collection

Owner direction: build the six theme options presented in conversation, with bold storm presentation. Preserve readable and usable roofing workflows.

## Approach
Extend existing React/Next.js theme and radar components. Original generated photographic plates with CSS 3D camera depth, independent radar/light/particle layers and a vector Professional scene provide portable animated artwork without video downloads, paid assets, WebGL dependencies, or invented live weather. Professional, Tornado Alley, Storm Tracker 11, Hail Core, Lightning Front, After the Storm. The Storm Tracker scene includes a photorealistic meteorologist and recognizable Atlanta skyline and command-center screens. This implementation is layered 3D-parallax interface artwork, not a rigged 3D human, rendered video, or an 8K trailer. Command center exposure is balanced slightly below the bright revision, per owner direction. First-time login defaults to Storm Tracker 11; explicit Professional preference is respected.

## Behavior
- One global saved per-device collection preference: theme, sound opt-in, motion auto/reduced/full, low-power mode, intro on/off.
- Existing professional/storm toggle remains compatible: last selected storm theme is remembered. Old storm preference migrates to Storm Tracker 11. No account synchronization is claimed.
- Theme selection and controls available in Settings and on the public /themes page linked from login and app header. Previews do not persist until Apply. Intro replay, skip, Escape, and focus restoration; first intro once per session when enabled. No login interruption. A real 36-second H.264/AAC trailer is available through an explicit Watch trailer with sound action; all page roots share the selected scene and palette.
- Scenes appear behind every app/login surface. Sound synthesized locally only after explicit user interaction, stops when muted/hidden/unmounted. OS reduced-motion always respected; low-power mode freezes scenes and disables sound.
- Real Doppler remains the existing location-aware /radar screen, linked directly from Storm Tracker and previews. No fabricated observations or warning tickers.
- Route transitions choose story chapters (inspection, estimate, production, invoice, warranty). Navigation is not claimed as proof of a job action. Real business data is untouched.

## Verification
Runtime preference tests cover invalid JSON, legacy migration, denied storage, remembered storm choice, reset, and DOM synchronization. Browser tests exercise Apply vs Preview, persistence, reversible Professional, reduced motion, intro skip/focus, mobile overflow, and all six scenes. Existing theme, auth, radar, security and full CI checks remain required.
